# Algoritmos Base do machine learning

Machine Learning é bastante complexo, muito porque seus algoritmos são complicados de entender. Um algoritmo usa outro por dentro, podendo trocar qual opção interna usa, deixando tudo mais confuso. Portanto esses algoritmos mais basais serão explicados aqui, antes de ir para o algoritmos principal.

Os algoritmos explicados aqui são:

- **Mínimos Quadrados**: Usado em regressão linear. Possui uma penca de variações
- **Máxima Verissimilhança**: Usado pelo gradiente descendente e exige um conhecimento matemático muito específico
- **Gradiente descendente**: Usado em regressão linear e logística
